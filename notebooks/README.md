# Sample notebooks

Getting-started notebooks for the Sigmodata models on AWS Marketplace. Each deploys the
model package you subscribed to, runs a few examples and deletes the endpoint. Paste the
**Model Package ARN** from AWS Marketplace (*Continue to Configuration*) into the first
code cell. These files are generated and mirrored from the product source; open an issue
rather than a pull request for changes.
